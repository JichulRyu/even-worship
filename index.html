악보 사진 가져오기

검색된 원본을 열고 이용 권한이 있는 악보 사진 또는 캡처를 선택하세요. AI 없이도 G2 전체 화면에 맞춰 표시할 수 있습니다.

AI 인식은 위 Gemini API 키를 사용하고 Google로 사진을 전송합니다. 인터넷 검색 기능은 사용하지 않습니다. 이용 가능 모델과 할당량에 따라 비용이 발생할 수 있습니다. 사진 직접 표시는 API 키가 필요 없습니다.

데이터 및 자동 검색 설정

정식으로 이용 허락받은 무료 악보 API만 설정하세요. 제공처의 CORS 허용 및 access: free, reuseAllowed: true, license 필드가 필요합니다. 제목이 일치하고 가사·코드 자료가 확인되면 자동 전조 및 표시합니다.

응답: {"songs":[{"title":"…","key":"G","body":"[G]…","source":"…","access":"free","reuseAllowed":true,"license":"이용 허락 근거"}]}. body 대신 chordpro 또는 lines 배열도 지원.

JSON 라이브러리 또는 ChordPro 파일 가져오기. Gemini는 검색 출처를 추천하며, 악보 전문을 자동 복제하지 않습니다.

악보 등록 / 수정

코드를 [G], [D/F#], [Em7]처럼 가사 중간에 넣으세요. {comment: Chorus}는 구간명입니다.
