데이터 및 자동 검색 설정

이용 허락을 받은 악보 API가 있다면 HTTPS 주소를 입력하세요. 제목 검색 시 로컬 결과가 없으면 자동 조회합니다. 제공처의 CORS 허용이 필요합니다.

응답: [{"title":"…","key":"G","body":"[G]…","source":"…"}] 또는 {"songs":[…]}

JSON 라이브러리 또는 ChordPro 파일 가져오기. Gemini는 검색 출처를 추천하며, 악보 전문을 자동 복제하지 않습니다.
