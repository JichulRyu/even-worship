# Even Worship v0.4.0

Even Realities G2 CCM 악보 표시 프로토타입.

## 웹 실행
https://jichulryu.github.io/even-worship/?v=040

## 검색
- Tavily 키를 등록하고 제목 + 키(예: 믿음과 삶 G)를 검색합니다.
- 블로그 및 무료 공개 악보 후보를 우선하고 알려진 판매처와 유료 표현을 제외합니다. 검색 결과만으로 무료 열람 여부나 재사용 허락을 확정할 수 없습니다.
- 일반 블로그 악보 전문을 자동으로 가져오는 기능은 없습니다.
- 이용 권한이 있는 사진을 선택하면 전체 화면 표시하거나 Gemini 이미지 인식으로 편집할 수 있습니다.

## 자동 표시 데이터
재사용을 허락받은 무료 악보 API의 HTTPS 주소를 설정합니다. CORS 허용 필요. 다음처럼 응답해야 합니다.

```json
{"songs":[{"title":"창작 테스트","key":"G","body":"[G]창작 [D]테스트","source":"직접 작성","access":"free","reuseAllowed":true,"license":"작성자 이용 허락"}]}
```

body 대신 chordpro 또는 lines 배열(lyrics, chords: [{pos, chord}], section)도 지원합니다. 제목이 정확히 일치하고 무료 및 이용 허락 메타데이터가 있는 곡만 자동 변환/전조/표시합니다. API 공급자가 표시한 허락 근거는 운영자가 검증해야 합니다.

## G2 음성 검색 (미검증)
- Even Hub WebView에서 G2 연결. 앱의 g2-microphone 권한 및 네트워크 권한이 필요합니다. 현재 GitHub Pages 웹앱만 업로드되어 있고 정식 Even Hub 패키지는 별도 준비가 필요합니다.
- Groq API 키(https://console.groq.com/keys)를 입력하고 음성 검색을 허용합니다.
- 안경/R1 두 번 터치 또는 G2 음성 검색 버튼으로 5초간 녹음한 뒤 Groq Whisper로 전송, 인식한 제목으로 검색합니다.
- 음성 검색이 활성화되면 두 번 터치의 기존 종료 기능을 대체합니다. 스와이프는 페이지/곡 전환.
- 실제 G2, R1, Groq 네트워크 호출, 마이크 권한은 아직 테스트하지 않았습니다.

## 보안
API 키는 메모리 입력만 지원하며 공개 코드에 넣지 마세요. 공개 운영은 인증, 사용량 제한, 서버 측 키 보관이 필요합니다. 음성은 Groq, 검색 제목은 선택한 검색 서비스, 사진 인식은 Gemini로 전송됩니다. 서비스별 할당량/요금제를 확인하세요.
